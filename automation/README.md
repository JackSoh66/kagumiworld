# 在 Codex 中登记每日任务

这里保存的是可复用任务说明，不是已生效的排程。仓库不会通过 GitHub Actions、cron、API Key 或常驻进程启动生成器。

在 Codex 的 Automations / 自动化界面创建任务，选择 `kagumiworld` 项目及其可用的运行环境，并使用：

- 名称：`Kagumi World 每日创作`
- 时间：每天 `09:17`
- 时区：`Asia/Kuala_Lumpur`（UTC+8）；若界面只使用本机时区，请按显示的时区换算。
- 任务内容：复制下面的整段指令。

```text
在 JackSoh66/kagumiworld 项目执行 automation/daily.md 的完整每日创作流程。每天按 Asia/Kuala_Lumpur 日期，实际研究至少两个可访问的当下参考，自主选择一个有新意的网页交互作品并完成，不需要每天确认选题。形式不限于小系统、landing page、创意工具或艺术实验。保留旧作品，新增独立页面、预览、索引、中文研究笔记和真实交互测试。当天已有作品则跳过。按任务说明验证、构建并运行桌面/手机版测试；全部通过后 commit 并 push 到该 repository 的 main，验证远端提交后用中文汇报。用户已授权这一每日提交与推送。使用已有项目与 Git 身份认证，不调用 GitHub Actions，不要求 GitHub Actions 的 OPENAI_API_KEY。遇到无法解决的网络、账户额度或写入权限问题，保留工作并如实报告，不能声称已完成或已推送。
```

执行任务的环境需要仓库访问、网络研究、运行测试、写入和推送权限；Codex 的实际账户额度与自动化运行条件仍然适用。若任务只能在本机运行，遵循应用显示的在线/唤醒条件，不依赖本次临时云机器持续运行。查看界面确认任务的状态与下次运行时间；首次真实运行完成后再检查运行结果。

本次会话可调用的工具及 Codex CLI 没有提供定时任务创建入口，所以尚未替用户登记 Automation。修改本文件、保存云环境草稿或推送代码，都不等于已创建定时任务。

停止或调整排程，应在 Codex 的 Automations 界面编辑或暂停该任务。修改 `automation/daily.md` 仅调整后续任务内容，不改变调度时间或启用状态。
